# Prosto bookmark
PWA приложение для хранения закладкок на Vue.js 2 и Laravel 8

## Установка
- `composer install`
- `npm install`
- заполнить `.env`

## Для разработки
- PWA клиент разрабатывать через `npm run watch`. 
- Для сборки клиента использовать `npm run prod`.
- Документация на методы API есть в Postman коллекции `bookmarks`.
